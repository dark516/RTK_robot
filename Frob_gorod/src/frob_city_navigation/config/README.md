# Конфигурации Frob City

Сохранены профили финальной рабочей сборки от 13 сентября 2026 года:

- `andrey_manual_field.yaml` — ручная калибровка геометрии поля.
- `andrey_competition_*.yaml` — сгенерированная топология, событие, восприятие, навигация, исполнитель, motion guard, readiness и Nav2 для соревновательного запуска.
- `lab_*.yaml` — отдельные лабораторные проверки.
- `wp*_test_*.yaml` — профили разработки; они не являются измеренной картой другого полигона.

`competition_profile.py` строит соревновательную геометрию из ручной калибровки; её согласованность проверяется в `test/test_competition_profile.py`.

Полевой motion guard сохранён с `commissioned: true` и ограничением 0,12 м/с. В исходном профиле торможение было консервативной оценкой; при переносе на другую платформу или поле требуется повторная физическая калибровка. Общий шаблон `motion_guard.yaml` и тестовые профили не следует подменять соревновательным профилем без проверки геометрии и оборудования.
