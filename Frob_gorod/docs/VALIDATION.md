Тесты запускаются из `Frob_gorod` после сборки и загрузки `install/setup.bash`:

```bash
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python -m pytest -q
```

Манифест интерфейсов проверяется отдельно:

```bash
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python -m pytest -q src/frob_city_interfaces/test/test_interface_manifest.py
```

Настройка `pytest.ini` выбирает тесты городского стека и отдельную регрессию остановки Arduino. Шаблонные copyright/flake8/pep257-проверки старых базовых пакетов не входят в этот результат. Начальные попытки проверки до сборки ROS-интерфейсов и из неверного рабочего каталога не учитываются как верификация релиза.

Сборка выводит предупреждения исходных пакетов о setuptools/`tests_require`, marker-файлах и старом CMake/C++ SDK лидара; ошибок сборки нет. Аппаратные узлы при проверке launch-аргументов не запускались. Камера, лидар, моторы и полный физический заезд на полигоне в этой сессии не проверялись. Тест на пустом изображении подтверждает загрузку модели и исполнение инференса, но не качество распознавания знаков.
