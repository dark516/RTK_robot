# Происхождение восстановленной версии

Обновление подготовлено 14 ноября 2026 года. Базовая версия: `dark516/RTK_robot`, commit `dfa95b5a0d09c90261ad0ae4027a879ff77e7347`.

Источник городского стека — последняя сохранённая сборка `competition_impl/src` из работы 13 сентября 2026 года. По истории задач она собрана из исходников робота с последующими соревновательными правками: геометрия и профили, преобразование позы в map через TF, остановки и парковка, motion guard, запуск робота и ноутбука. Старые промежуточные снимки поверх этой версии не накладывались.

Добавлены пять пакетов: `frob_city_navigation`, `frob_city_interfaces`, `frob_city_web`, `traffic_sign_detector`, `traffic_sign_interfaces`. Обновлены шесть общих файлов базовой платформы: bringup, Nav2, EKF, настройки и реализация колёсной одометрии, Arduino bridge. Исходные вспомогательные GUI и драйвер YDLidar сохранены; их отсутствие в локальном снимке не считалось указанием удалить их из репозитория.

Не перенесены каталоги сборки, логи, pycache, резервные копии и временные файлы. Включены сохранённые веса YOLO и отдельная лабораторная карта. Дополнительно восстановлены три ранее сохранённых теста TCP-передачи детекций. При переносе исправлены привязки к каталогам: обязательный путь к домашнему каталогу разработчика заменён использованием Python-окружения с необязательным `ultralytics_vendor_path`. Каталоги калибровки веб-панели разрешаются относительно домашнего каталога текущего пользователя; карты из установленного frob_navigation доступны в панели. В манифестах bringup/odometry перечислены используемые аппаратные пакеты и robot_localization, чтобы выборочная сборка включала их зависимости. Настройка pytest включает общий каталог тестовых помощников и исключает старые шаблонные линтеры базовых пакетов. README конфигураций и модели приведены в соответствие с фактическим содержимым.

Текущий Raspberry Pi не опрашивался. Восстановление исходников не доказывает, что каждый сохранённый профиль был применён в зачётной попытке. Спортивный результат команды подтверждается отдельно документом команды и публикацией НИТУ МИСИС.
