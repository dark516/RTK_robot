# Происхождение снимка кода

Папка объединяет два развёртывавшихся отдельно workspace:

- `robot_ws` — снимок платформы из репозитория
  [`dark516/sverk_rover_normal_wheel`](https://github.com/dark516/sverk_rover_normal_wheel),
  исходный commit `9a4e7cc71940e9e7565b76f042e049a25d2cd0e7`, дополненный последней локальной
  конфигурацией LLM-агента;
- `ai_ws` — снимок рабочего `rover_vision` из ноутбучного `rtk_ws`, включающий
  LLM gateway, VLM diagnostics и path-clearance CV.

Результаты `colcon`, локальные калибровки, сертификаты, логи, веса и собранный
`llama.cpp` намеренно не копировались. Это делает папку пригодной для Git и не
раскрывает секреты, но требует выполнить шаги из `REPRODUCIBILITY.md`.


## Изменения при проверке 14 ноября 2026

Папка подготовлена в исходной задаче Codex `01a0e2f2-b960-7732-a285-90741b88353d` и перенесена из локального клона без изменения оригинала. При повторной проверке установлено, что полный сценарий эвакуации, описанный ранее в README, не сохранён в исполняемом MCP-коде. Документация исправлена по фактическим модулям.

Физическая миссия и модели не запускались.

Исторические deploy/systemd-файлы сохранены как шаблоны и требуют адаптации. В Git не включены реальные bearer/API-ключи, TLS-ключи, GGUF и калибровки.
