# Что реализовано в сохранённом снимке

Проверка проведена 14 ноября 2026 года по исходникам, а не только README.

| Область | Свидетельство | Статус |
|---|---|---|
| LLM gateway | `ai_ws/src/rover_vision/rover_vision/local_llm_gateway.py` | Управление локальными моделями и API реализованы |
| VLM | `vlm_diagnostic.py`, `vlm_diagnostic_node.py` | Классификация события, визуальное наличие QR, Trigger-service |
| CV | `path_clearance.py`, `path_clearance_node.py`, `calibration_library.py` | Проверка по эталонам и переключение профиля по входящей позе |
| MCP | `robot_ws/src/agent/rover_agent_mcp/rover_agent_mcp/tool_schemas.py`, `ros_bridge.py` | Ограниченные команды движения, Nav2, состояния и подсветки |
| Поиск по статическому ориентиру | `search_static_obstacle` есть только в форматтере результата и тесте | Исполнитель и MCP-schema отсутствуют |
| Положение в клетке | CV читает JSON `/rover/grid_pose` | Издателя нет в сохранённом robot_ws |
| QR | VLM сообщает present/absent/unknown | Полное декодирование полезной нагрузки в этой копии не реализовано |
| Автовозврат и объезд области | Нет связанного mission executor | Требуется отдельная интеграция |

Доступные инструменты включают `navigate_to_pose`, `cancel_navigation`, `get_navigation_status`, `is_navigation_ready`, `get_robot_pose`, `get_laser_summary`, `stop_motion`, относительные движения и подсветку. Они не образуют автоматически полный сценарий эвакуации.

`robot_ws` содержит аппаратный вариант `rover_vision` (camera detector); `ai_ws` — отдельный вариант этого пакета (LLM/VLM/CV). Их нельзя собирать одним colcon workspace или накладывать в одном shell: победит один пакет. В документированном варианте CV работает на ноутбуке и получает HTTP-кадр с робота; историческое размещение на Raspberry Pi требует отдельного развёртывания.

Часть наследованных подписей аппаратной конфигурации описывает mecanum-rover, хотя имя исходного репозитория содержит normal_wheel. Геометрия и порядок моторов не изменялись по догадке: их необходимо сверить с реальной платформой.

Для завершения полной миссии нужны исходники исполнителя либо новая разработка: калиброванное преобразование map→клетка, привязка ориентиров, план поиска, таймауты и отмена, QR-декодер, возврат и аппаратные испытания. Восстановление репозитория не выдаёт такую интеграцию за существующую.
