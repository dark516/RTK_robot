Дата: 14 ноября 2026 года. Среда: Ubuntu 24.04, ROS 2 Jazzy, системный Python 3.12. Сборки робота и AI выполнялись изолированно в отдельных каталогах; оборудование не подключалось.

| Проверка | Результат |
|---|---|
| robot_ws: colcon build | **20 пакетов собрано** |
| ai_ws: colcon build | **1 пакет собран** |
| AI unit/HTTP/packaging/launch | **25 passed** |
| Агент и фильтр лидара | **7 passed** |
| Импорт всех трёх AI console entrypoints | Успешно |
| Gateway с реальными ROS 2-интерфейсами и autostart=false | HTTP 200, state=stopped |
| Gateway: запрос инференса без ключа | HTTP 401 |
| Gateway: loopback HTTP proxy с имитированным backend | Проверен в unit-тесте |
| Загрузчик моделей | bash syntax / --help проверены, веса не скачивались |
| Python syntax | Все Python-файлы проверены AST |
| Источники результата | Официальный пост cuprtc/2383: 3 место, 111 баллов, три ФИО |
| Скриншот результата | Сделан в браузере с публичной страницы Telegram и просмотрен |

Инструкции тестов — в [REPRODUCIBILITY.md](REPRODUCIBILITY.md). В результате 32 теста; это не результат lint-проверок всех сторонних ROS-пакетов.

`rosdep check` AI после исключения `ament_python` не показывает недостающих системных зависимостей. Для robot_ws текущая база rosdep не разрешает старый ключ `ament_pytest` и `python3-spidev`; инструкции явно указывают skip-keys и установку spidev через apt. Необязательный `python3-paho-mqtt` отсутствует в тестовой среде, поэтому fleet bridge в этой проверке не запускался. Его установка описана в инструкции. Сборка сама по себе не доказывает готовность аппаратных драйверов.

Сохранены предупреждения исходных SDK/CMake и setuptools о старых метаданных. Отсутствующие исходные зависимости AI и нерабочий entrypoint исправлены, а не скрыты.

GGUF-веса не загружались, реальные LLM/VLM-запросы и качество распознавания не проверялись. Камера, лидар, приводы, навигация по физическому полю, полный поиск, QR и возврат не проверялись. Полный mission executor и источник grid_pose отсутствуют в сохранённых исходниках, что отражено в README и IMPLEMENTATION_STATUS.md.
